# 快办（KuaiBan）— 业务逻辑设计 v0.1

> 本文档只讨论**业务逻辑**（软件怎么运转），不涉及编程实现。
> 状态：讨论稿，待用户确认后定稿为 v1.0。

---

## 0. 产品定位

**一个会自己记着事、到点会喊你、平时不烦你的桌面小挂件。**

面向人群：自制力差、记忆力差、做事没条理的人。

三条设计铁律：
1. **极速捕获** —— 记录任何东西不超过 2 秒，不许选日期、选分类、选优先级。
2. **自动兜底** —— 没做完的事由软件主动搬到今天，不指望用户想起来。
3. **安静存在** —— 平时几乎看不见，只在"该提醒的时候"出现。

---

## 1. 平台策略（重要）

最终目标平台：Windows → macOS → Android → 鸿蒙 OS → iOS（能支持最好）。

### 1.1 大脑 / 外壳 分离

| 层 | 内容 | 说明 |
|---|---|---|
| **大脑** | 待办规则、重复规则、逾期顺延、提醒调度、数据读写 | **只写一份**，所有平台共用 |
| **外壳** | 界面外观、贴边挂件、闪动动画、声音、托盘、开机自启、系统通知 | 每个平台各做一层 |

**好处**：功能不会各平台跑偏；新增平台只是"换个外壳"；改 bug 只改一次。

### 1.2 第一版范围

只做 **Windows 桌面版**，但大脑从一开始就按"平台无关"来设计。

### 1.3 数据互通（待确认）

当前定位是单机软件、无账号。但多端之后必然出现"电脑上记的，手机上看不到"。
无账号前提下有几种做法（详见第 8 节），需用户拍板。

## 2. 数据模型

### 2.1 「事项」的字段

| 字段 | 必填 | 说明 |
|---|---|---|
| 内容 | 是 | 一句话，最多约 200 字 |
| 日期 | 否 | 哪一天做。**空 = 未排期，自动进「随笔」区** |
| 时间 | 否 | 几点几分。**空 = 全天事项，不打扰式提醒** |
| 提醒开关 | 是 | 默认开（有时间）/ 关（无时间） |
| 提前量 | 否 | 提前 0/5/15/30/60 分钟提醒，默认 0 |
| 重复规则 | 否 | 不重复 / 每天 / 每周（选周几）/ 每月（选几号）/ 工作日 |
| 状态 | 是 | 未完成 / 已完成 / 已取消 |
| 顺延次数 | 是 | 被推迟过几次（默认 0，**核心字段**） |
| 完成时间 | 否 | 用于归档与统计 |
| 备注 | 否 | 折叠，展开才看到 |

### 2.2 核心设计：只有一份数据，四个视角

「今天 / 明天 / 日历 / 随笔」**不是四个篮子，而是同一份数据的四种看法**：

- 今天清单 = 日期是今天的
- 明天清单 = 日期是明天的
- 日历 = 按日期摊开的总览
- 随笔 = **日期为空**的事项

好处：在日历上把事挪到明天，明天清单立刻就有了，不用重新录一遍。

## 3. 核心机制一：逾期顺延（本软件的灵魂）

### 3.1 规则

1. 到了新的一天，昨天（及更早）未完成的事项 **不删除、不改日期**。
2. 它们自动出现在**今天清单最顶部**的「⚠ 昨日未完成 (N)」区域。
3. 每条事项累计**顺延次数**。
4. 顺延次数 ≥ 3 时，软件温和提示：
   > 这件事已经放了 3 天了，要不要改个时间、拆小一点，或者放弃？
   并给出三个按钮：`改期` / `今天一定做` / `放弃`
5. 区域内的每条支持一键：`搬到今天` / `改期`。

### 3.2 为什么不在原日期上直接改

保留原始日期 = 保留"这件事拖了多久"的真相。用户最需要看到的就是这个真相。

### 3.3 一天的起点

**建议：凌晨 04:00 为分界线**（而不是 00:00）。
理由：用户熬夜到凌晨 1 点还在处理"今天"的事，此时日历不该已经翻页。
（待用户确认，见第 10 节）

## 4. 核心机制二：提醒引擎

### 4.1 三级递进

| 阶段 | 时机 | 表现 |
|---|---|---|
| L1 静默提示 | 到点瞬间 | 挂件图标**闪动** + 红色数字角标 + **响一声**。**不抢焦点**，不打断当前工作 |
| L2 气泡确认 | L1 后 1 分钟仍未处理 | 弹出小气泡，按钮：`完成` / `推后10分钟` / `推后1小时` / `今天不再提醒` |
| L3 升级 | L2 后仍不处理 | 角标数字持续累积，不重复弹窗（避免烦人） |

### 4.2 提醒风暴的处理（必须有）

同一时刻有 5 件事到点 → **合并成一条提醒**：
> 你有 5 件事到点了
> - 交周报
> - 给客户回电话
> - …
> 按钮：`全部推后10分钟` / `逐个处理`

**绝对不允许**弹出 5 个窗口。

### 4.3 错过与漏提醒

- 电脑睡眠/关机期间错过的提醒：开机后汇总一条「你错过了 3 个提醒」，不逐个补弹。
- 全天事项（没设时间）：只在早上约定时间汇总一次，例如「今天有 5 件事」。

### 4.4 免打扰

- 默认免打扰时段：**22:00 – 07:00**（待确认，可关闭）
- 免打扰期间：只闪图标、不响声音、不弹气泡
- 可设「例外」：标记为重要的事项依然提醒

## 5. 核心机制三：重复任务

第一版支持：不重复 / 每天 / 每周（选周几）/ 每月（选几号）/ 工作日。

### 5.1 生成方式

重复任务不预先造出几百条记录，而是**用到时才生成当天的实例**（保证性能，符合"速度要快"的要求）。

### 5.2 完成与系列的关系

- 勾选完成 = **只完成这一次**，系列继续存在。
- 某一次不做了 → 用「跳过本次」，而非删除。

### 5.3 编辑与删除（第一版简化）

- 编辑重复任务：第一版统一「**修改整个系列**」，不做"只改这一次"。
- 删除时询问：`只删这一次` / `删除整个系列`。
- 前端表现：重复任务在清单里带一个小图标（🔁），一眼可辨。

## 6. 四个模块的具体规则

### 6.1 今天清单（早上做规划的人）

- 从上到下：**昨日未完成区** → **今天的待办** → **已完成（折叠）** → **输入框**
- 排序：按提醒时间升序；无时间的排最后
- 顶部常驻：今天日期 + 未完成数量（如「今天还有 4 件」）
- 输入框：敲回车即存，默认落到今天，默认无时间

### 6.2 明天清单（下班前做规划的人）

- 就是"日期 = 明天"的视图，与今天清单共用同一套界面，一个按钮切换
- 用于下班前把明天的安排排好

### 6.3 日历清单（记录未来固定时间的事）

- 月视图：有事的日子下方打点（可显示条数）
- 点某一天 → 右侧/下方列出当天事项
- 支持对某条 `改期`（第一版用按钮改期，不做拖拽）
- 日历是**查看与安排的入口**，不是第四个数据容器

### 6.4 随笔记录（抓住瞬间灵感）

- **全局快捷键**（如 `Ctrl+Alt+Q`）随时呼出输入框，输入 → 回车 → 存好，**不问任何问题**
- 存进去就是"未排期"状态，安静躺在随笔区，不提醒、不打扰
- 每条右侧有 `→ 排期`：一键变成今天/明天/某天的待办
- 定位：**待办的暂存区（Inbox）**，灵感不会烂在笔记本里

## 7. 桌面挂件（外壳形态）

### 7.1 显示与隐藏

| 用户动作 | 软件反应 |
|---|---|
| 鼠标移到屏幕最右侧边缘的窄条 / 小图标 | 面板滑出（约 0.15 秒动画） |
| 鼠标移开 | **延迟 1.5 秒**再收起 |
| 正在输入文字 / 正在勾选 | 不收起 |
| **单点击**小图标 | **钉住**（pin）常显，再点一次收起 |
| 最小化：双击 / 按 Esc | 收回到只留小图标 |

> 说明：原始需求是"移开就隐藏"，但那样鼠标一滑出去、正在打的字就没了。加 1.5 秒延迟 + 输入时不收起 + 点击可钉住，体验才成立。

### 7.2 小图标的形态

- 位置：屏幕右侧垂直居中，宽约 6–10px 的窄条 + 一个小圆点/图标
- 常显信息：未完成数量角标
- 到点提醒时：**闪动**（即使鼠标不在附近）
- 特性：不抢焦点、不占任务栏、不遮挡其他窗口操作

### 7.3 视觉要求

- 面板宽度约 320–360px，高度自适应内容，最大不超过屏幕 80%
- 整体轻、快、无多余装饰；打开到可输入应在 200ms 内

## 8. 数据与安全

### 8.1 存储

- 单一数据文件（SQLite），存放在用户数据目录
- 纯本地，无账号、无联网上传

### 8.2 防丢失（必需功能，不是附加功能）

- **每日自动备份**，保留最近 7 份
- **一键导出**（JSON 文件）与**一键导入恢复**
- 换电脑 = 拷走数据文件即可

### 8.3 多端数据互通（待确认）

无账号前提下，可选方案：

| 方案 | 说明 | 优点 | 缺点 |
|---|---|---|---|
| A. 纯单机 | 各设备数据独立 | 最简单、最符合原始需求 | 手机和电脑对不上 |
| B. 同步文件夹 | 数据文件放进 OneDrive / 坚果云 / iCloud 目录 | 无账号、自动同步 | 需要用户自己装网盘；并发冲突需处理 |
| C. 局域网直连 | 电脑与手机同一 WiFi 下互传 | 无第三方 | 实现复杂，跨平台成本高 |
| D. 二维码/文件互传 | 手动导出、扫码导入 | 简单可控 | 不自动，容易忘 |

**建议：第一版按 A 做（但数据层设计成"单文件可整体搬迁"），架构上为 B 预留。**

## 9. 功能边界（第一版做什么 / 不做什么）

### 9.1 第一版必做（8 项）

1. 今天清单（含昨日未完成自动带入）
2. 明天清单
3. 日历视图
4. 随笔收件箱 + 全局快捷键极速记录
5. 提醒引擎（三级递进 + 合并提醒 + 推后 + 重复任务）
6. 桌面右侧挂件（悬停展开 / 点击钉住 / 延迟收起 / 闪动）
7. 本地存储 + 自动备份 + 导出导入
8. 开机自启（可开关）

### 9.2 明确砍掉（避免变复杂）

- ❌ 子任务、多级清单、拖拽排序
- ❌ 账号、云同步、多人协作
- ❌ 番茄钟、统计报表、成就系统
- ❌ 标签体系、复杂分类树
- ❌ 主题换肤、皮肤市场

### 9.3 第二版再考虑

优先级、搜索、自定义快捷键、多显示器适配、其他平台外壳。
