# 快办（KuaiBan）

> 一个会自己记着事、到点会喊你、平时不烦你的桌面小挂件。

面向「自制力差、记忆力差、做事没条理」的人：早上规划今天，下班前排好明天，
想法来了随手记下，到点软件主动提醒，平时缩在屏幕最右边几乎看不见。

## 🏗 技术栈

| 层 | 技术 |
|---|---|
| 界面 | Vue 3 + Vite + TypeScript |
| 大脑 | 纯 TypeScript（零平台依赖，全平台复用） |
| 外壳 | Tauri 2 |
| 本地存储 | SQLite |
| 服务端 | Node.js + Fastify + PostgreSQL + Docker |

**核心架构：四层分离**（界面 / 大脑 / 平台桥接 / 外壳）

> ⚠️ **铁律：`packages/core`（大脑）里绝对不允许出现任何平台专属代码。**
> 不许 import 窗口、托盘、通知、文件系统、HTTP 客户端。所有平台能力通过接口注入。
> 检验方法：大脑包能在纯 Node 环境跑单元测试、不报任何平台错误。

## 🚀 开发

**前置要求**：Node ≥ 20、pnpm、Rust（[rustup.rs](https://rustup.rs)）

```bash
# 安装依赖
pnpm install

# 启动桌面客户端（开发模式，带热更新）
pnpm dev

# 构建安装包
pnpm build

# 跑大脑的单元测试（148 个，纯 Node 环境，无需任何平台依赖）
pnpm test

# 全仓类型检查
pnpm typecheck
```

### 为什么 `packages/core` 的测试这么重要

它不只是测业务规则，更是**"大脑零平台依赖"这条铁律的机器可验证证明**：
一个跑在纯 Node 环境下、不报任何平台错误的测试套件，说明大脑里确实没有混进
窗口 / 托盘 / 文件系统 / SQLite 这类平台 API。守不住这条，将来每上一个平台都要改一遍大脑。

### 大脑 `@kuaiban/core` 已实现的规则

对应[业务逻辑设计](docs/快办-业务逻辑设计-v0.2.md)的每一节，全部有测试覆盖：

| 规则 | 实现要点 |
|---|---|
| **一天的边界 = 凌晨 04:00** | 熬夜到凌晨 1 点处理的事仍算"今天"，日历不会提前翻页 |
| **逾期顺延（灵魂）** | 昨天没做完的自动进「昨日未完成」区；**不需要任何定时任务** —— 只是业务日变了。逾期天数**派生**得出，不会和存储的计数不一致 |
| **逾期 ≥ 3 天提醒** | 进入 `needsAttention`，界面据此温和劝用户改期 / 拆小 / 放弃 |
| **重复任务** | 每天 / 每周（选周几）/ 每月（选几号）/ 工作日。**用到时才生成实例**，不预造几百条记录 |
| **完成单次不影响系列** | 勾选只记 `lastDoneDate`，系列继续；不做用「跳过本次」 |
| **提醒调度** | 用**时间窗**收集而非"等于此刻"，睡眠 / 卡顿后不漏提醒 |
| **提醒风暴合并** | 多件事同时到点 → 合并成一条，**绝不弹 N 个窗口**（生死线） |
| **免打扰** | 默认 22:00–07:00，支持跨午夜区间 |
| **全天事项** | 不逐条打扰，只在早上汇总一次 |

### 核心机制：不抢焦点 与 能输入 如何共存

`WS_EX_NOACTIVATE` 的代价是窗口永远拿不到键盘焦点 → 输入框打不了字。
两者在 Windows 上**物理互斥**，方案是「按需临时激活」：

```
平时            → WS_EX_NOACTIVATE 在位，点面板任何地方都不夺焦点
用户点输入框    → 摘掉 NOACTIVATE + SetForegroundWindow（不 SetFocus！）
失焦/收起/Esc   → 立刻装回 NOACTIVATE，并把焦点还给原窗口
```

> ⚠️ **绝不能补 `SetFocus`，激活也绝不能由 focus 事件驱动。**
> 实测会把 WebView2 拖进每秒上千次的 focus/blur 死循环，键盘输入全丢。
> 详见 [验证报告](docs/windows-verify/README.md) 第 4 节。

三条归还路径保证不会卡在可激活状态：输入框 blur、面板收起、80ms 轮询看门狗。

### 手感细节（都是实测调出来的）

| 细节 | 取值 | 为什么 |
|---|---|---|
| 悬停命中区高度 | 可见窄条 152px ± 8px 容差 | 一开始用了整个窗口高度（560px），结果在窄条上下方的**空白处**悬停也会弹面板，会吓到用户 |
| 收起延迟 | 移开 1.5 秒 | 太短会误收，太长显得迟钝 |
| 打字时 | **绝不收起** | 打字时手会离开鼠标、鼠标容易滑出窗口；不挡这一条，1.5 秒后面板就被收走、草稿白打 |
| 兜底收起 | Rust 侧 3 秒 | 明显长于前端的 1.5 秒，只在前端收不到 `mouseleave` 时救场，正常路径绝不抢跑 |
| 托盘唤起 | 等价于**钉住** | 从托盘唤起时鼠标没进过窗口，收不到 `mouseleave`；不钉住的话面板会一直开着且用户不知道为什么 |
